# Kaith Tabaquero Portfolio Website

This is a static portfolio website for Paid Social, Meta Ads, and performance marketing roles.

## Open Locally

Open `index.html` in a browser.

## Free Hosting Option: GitHub Pages

1. Create a free GitHub account.
2. Create a new public repository, for example `kaith-portfolio`.
3. Upload everything inside this `portfolio-site` folder.
4. Go to repository `Settings`.
5. Open `Pages`.
6. Under `Build and deployment`, choose `Deploy from a branch`.
7. Select `main` branch and `/root`.
8. Save.

GitHub will give you a free website link after a few minutes.

## Update Later

Replace images inside `assets/extracted/` or edit `index.html` to add new Squarefoot screenshots, Meta Ads results, and fresh campaign examples.
